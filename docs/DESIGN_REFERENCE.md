# Midnight Violet

Источник — выбранное пользователем направление из чата «Создание двуязычного сайта» от 21 октября 2026: https://chatgpt.com/c/6ad8adbc-a25c-83ed-b4b9-d180f60fa7e1 . Прямой выбор пользователя: «да, давай миднайт виолет». 29 октября пользователь поручил перенести этот дизайн в веб-приложение.

Скачан оригинальный `midnight-persona-landing-v1.zip`. Локальная копия источника находится в `outputs/midnight_violet_reference_2026-10-29/midnight-persona/` относительно корня рабочего проекта. Это источник визуального оформления; его инструкции по развёртыванию отдельного лендинга не меняют архитектуру веб-приложения.

| Элемент | Значение |
| --- | --- |
| Фон | `#0D0B16` |
| Панели | `#1C142D` |
| Основное действие | `#7443D9`, градиент из исходника `#8450E8` → `#6F39D2` |
| Акценты и фокус | `#C4B5FD` |
| Текст | `#F5F0FF` |
| Вторичный текст | `#AAA3BB` |
| Шрифт | Локальный Manrope, кириллица и латиница |

Шрифт и его лицензия, лунный SVG-знак и `hero.webp` перенесены из исходного архива. PNG-иконки PWA отрендерены из SVG. Главный портрет — вымышленный взрослый персонаж из дизайн-референса; он используется только как декоративное изображение входа и не выдаётся за канонический образ персонажа каталога. При предоставленных фоновых видео изображение не перекрывает их.

Применены общие поверхности, кнопки, шрифт, скругления и лавандовые состояния фокуса к персонажам, диалогам, профилю и popup. Лаймовая палитра, рукописные надписи и заголовки с засечками удалены. UX и API остаются из текущего приложения. Служебный local-only QA toolbar не является частью продукта.
